title: About the Hub
---

The EC2U Knowledge Hub is the central knowledge sharing and semantic search facility of the
[EC2U Alliance](https://www.ec2u.eu/). It gathers content from EC2U universities and external sources, and publishes it
as cross-linked datasets on areas of common interest, such as research units, degree programs and courses.

Each dataset is available through this interactive semantic search tool and through a machine-readable REST/JSON-LD API.
Both support faceted search and linked data navigation across every dataset and its cross-links.

# Content

The hub harvests the public pages of EC2U universities and their partners on a regular schedule. It cleanses that
content, links related resources across datasets and uses [AI](legal/ai) to extract structured information from free
text. Every resource links back to the page it came from, which remains the authoritative source.

# Learn More

The reference pages document the content of each dataset and the structure of its data models.

- [API & Data Model](/api/) — the resource types of each dataset and the properties the API returns for them
- [Taxonomies](/taxonomies/) — the shared topics, levels and types that classify resources across datasets

# Get Involved

The coverage and quality of the hub rest on the people who publish, maintain and reuse its content. The guides below
explain what each role involves, how to get started and where to turn for questions and support.

- [Publishers](community/#publishers) — universities and partners publishing the harvested content
- [Webmasters](community/#webmasters) — teams maintaining the harvested websites and their markup
- [Developers](community/#developers) — anyone reusing the harvested data through the REST/JSON-LD API

# Support

The hub software is open source. Its code, issue tracker and development history are publicly available on
[GitHub](https://github.com/ec2u/data), which is also the channel for support requests and contributions.

- use the [feedback](community/feedback) button of any page to report an error in it or ask a question about it
- open an [issue][issues] to report a problem with the hub or its datasets, or to suggest a new feature
- start a [discussion][discussions] to ask a how-to question or to share an idea

[issues]: https://github.com/ec2u/data/issues

[discussions]: https://github.com/ec2u/data/discussions
