---
title: Guidelines
---

The guidelines set out the practices that help the hub harvest content from university sources completely and
accurately. They address the editors and maintainers of the web sites, feeds and catalogues the hub draws on. Each
guideline explains what to publish, in which form, and how it improves the quality of the resulting datasets. Sources
that follow them reach the hub sooner, with fewer gaps and errors, and need less manual correction afterwards.

- [Web Content](/about/guidelines/web-content) — how to structure web pages so that the hub reads them reliably
