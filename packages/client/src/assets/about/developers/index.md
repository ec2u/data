The EC2U Knowledge Hub publishes cross-linked datasets about the universities of the EC2U Alliance: their units,
programmes, courses, documents and events. Every dataset follows a shared data model, so content from different
universities can be compared, combined and reused without first cleaning the content of each source.

Each dataset is served through a machine-readable REST/JSON-LD API, alongside the interactive search pages. The API
supports the same faceted search and linked data navigation as the pages, so apps and analyses can build on every source
through a single interface, without integrating the website of each university on their own.

# Understanding the Data

- [Data Models](/about/models/) define the resources each dataset holds, the properties the API returns and the terms of
  the standard RDF vocabularies that each JSON-LD property maps to, linked to their definitions
- [Linked Data Models](../rdf/) introduces graph-based models and taxonomies for readers new to linked data

# Reusing the Data

Each dataset states the licence it is published under on its info page, reached through the info icon in the page menu.
Reuse a dataset within the terms of its licence, and credit the EC2U Alliance as its publisher. Content gathered from
partner universities remains subject to the rights of its original publishers, as set out in the
[Legal Notice](../legal/), so check those rights through the source link of each resource before reusing it.

Much of the content is collected by crawlers and enriched with AI. Read [AI Use Notice](../legal/ai) before relying on
generated descriptions, labels or classifications, and point your own users to it wherever you show them.

# Contributing to the Hub

The software running the hub is open source, released under the
[Apache License 2.0](https://github.com/ec2u/data/blob/main/LICENSE). Its code, issue tracker and development history
are on [GitHub](https://github.com/ec2u/data), where you can report errors in the data or the software, request features
and contribute changes to the software running the hub or to the datasets it publishes.
